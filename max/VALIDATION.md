# ADEPS-test Maxパッチ — 検証範囲

このフォルダのパッチは、ローカルの12ch識別用です。校正・補正フィルター・ニューラルADEPSを実装したパッチではありません。

## 自動テスト

リポジトリのルートから実行します。

```sh
npm run test:max
```

または、このフォルダで実行します。

```sh
node --test bridge.test.js
```

検査対象：

- OSC int32の符号、バイト順、文字列とゼロパディング。
- 未対応コマンド、範囲外ch、float、不正パケットの拒否。
- ping／pong、select／ack、mute／ackのローカルUDP往復。
- 同じポートの二重起動の失敗。
- Max JSONの接続先・入出力番号、12chの配線、初期ゲート0・音量0。
- 音量上限、チャンネル変更前のミュート、手動DSP、ブリッジ自動起動なし。

テストのUDP往復は一時的なローカルポートで行います。実際のMaxや音声デバイスを起動したことにはなりません。

## 別途必要な実機確認

Maxでのロードと画面表示、Node for Maxの起動、コンソール、DSP、選択した音声インターフェース、出力番号、スピーカー配線、実際の出音は、使用環境で確認してください。Danteを使用する場合は同期とsubscriptionも別の確認項目です。

パッチが初期音量0であることと、会場の音圧が適切であることは別です。メーターは生成信号を表示します。マイクの測定値やスピーカー到達を表示するものではありません。

## 参照した公開製品仕様

Maxの`node.script`、`gate~`、`dac~`、Node for Maxの`max-api`の仕様に基づいています。これらのライブラリ本体や音声機器設定を、このリポジトリから配布・変更する構成ではありません。
