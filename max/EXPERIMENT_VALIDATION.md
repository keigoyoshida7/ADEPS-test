# ADEPS_Experiment.maxpat / 検証記録

2026-09-11。Maxの音声デバイス・DSP・録音は開始していません。

## 実行した検証

`node build-experiment-patch.js && node --test experiment.test.js`：7件成功。

- パッチの再生成一致、全オブジェクトID・inlet/outlet・配線の妥当性、重複配線なし。
- 初期選択・RUN・GAIN・出力が0。DSPを起動する自動配線なし。ネットワーク／実行時JSなし。
- DACはGAINと単一出力ゲートを通るmonoだけ。FOAは4つのローカルbusだけ。
- 出力変更でGAIN 0が先に適用されることを制御イベントで確認。
- raw ADC1–19が同じ番号のsfrecord~19へ直接入ること、元mono保存が会場GAIN前であること。
- 保存パスを選ぶ前の録音開始を拒否し、停止後は新しい保存先が必要になる制御。
- A/B共通開始、重みだけの切替、共通停止、sfplay~のhalt bangで無限再帰しないこと。
- 単音源の停止／選択変更で別のファイルを開始しないこと。
- Sweepの端点20/20000 Hzと対数中間値、8秒の時間定義、両テストのフェードと停止経路。

イベント検証には、対象となる標準Maxオブジェクトの制御仕様を実装した小さなテスト用インタープリターを使います。MSPエンジン、ディスク録音、ドライバ、Max UIの代替検証ではありません。
